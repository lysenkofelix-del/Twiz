# 📚 Полная инструкция по настройке Twix Launcher

## 🎯 Что мы будем делать

1. Создадим репозиторий на GitHub
2. Загрузим туда лаунчер
3. Загрузим вашу игру как Release
4. Настроим автоматическую сборку через GitHub Actions
5. Получим готовый TwixLauncher.exe

**Время: 15-20 минут**

---

## 📋 Что вам понадобится

- ✅ Аккаунт на GitHub (бесплатный)
- ✅ Ваша игра в ZIP архиве
- ✅ Git установленный на компьютере (или GitHub Desktop)

---

# ЧАСТЬ 1: Создание репозитория на GitHub

## Шаг 1: Создайте репозиторий

1. Откройте [github.com](https://github.com)
2. Войдите в аккаунт (или зарегистрируйтесь)
3. Нажмите **зелёную кнопку "New"** (или +  → New repository)

### Заполните форму:

```
Repository name: TwixLauncher
Description: Официальный лаунчер для игры Twix
☑ Public (чтобы GitHub Actions работал бесплатно)
☑ Add a README file
☐ Add .gitignore (не нужно, у нас уже есть)
☐ Choose a license (опционально)
```

4. Нажмите **"Create repository"**

## Шаг 2: Загрузите код лаунчера

### Вариант А: Через Git (рекомендуется)

```bash
# 1. Клонируйте созданный репозиторий
git clone https://github.com/ВАШ_USERNAME/TwixLauncher.git
cd TwixLauncher

# 2. Скопируйте все файлы нашего лаунчера в эту папку
# (launcher.py, requirements.txt, build_exe.py, и т.д.)

# 3. Добавьте все файлы
git add .

# 4. Сделайте коммит
git commit -m "Добавлен Twix Launcher с поддержкой JAR"

# 5. Отправьте на GitHub
git push origin main
```

### Вариант Б: Через веб-интерфейс GitHub

1. На странице репозитория нажмите **"Add file" → "Upload files"**
2. Перетащите все файлы из папки `/home/user/Twiz/`:
   - `launcher.py`
   - `requirements.txt`
   - `build_exe.py`
   - `test_launcher_functions.py`
   - `README_RU.md`
   - `QUICK_START_RU.md`
   - `.gitignore`
   - `versions.json.example`
   - Папку `.github/` (важно!)
3. Напишите commit message: `"Добавлен Twix Launcher"`
4. Нажмите **"Commit changes"**

# ЧАСТЬ 2: Загрузка вашей игры на GitHub

## Шаг 3: Создайте Release для игры

1. На странице репозитория перейдите во вкладку **"Releases"**
2. Нажмите **"Create a new release"**

### Заполните форму Release:

```
Tag version: game-v1.0
   ↑ Это тег для вашей ИГРЫ (не лаунчера)

Release title: Twix Game v1.0

Description:
   Игра Twix версия 1.0

   Системные требования:
   - Java 8 или выше
   - RAM: минимум 2 ГБ, рекомендуется 4 ГБ

   Установка:
   1. Скачайте TwixLauncher
   2. Запустите и нажмите "УСТАНОВИТЬ"
```

3. В разделе **"Attach binaries"** перетащите ваш **game.zip** файл

   **Важно! Структура вашего ZIP:**
   ```
   game.zip
   ├── game.jar         ← Ваш JAR файл
   ├── assets/          ← Папки с ресурсами
   ├── data/
   ├── config/
   └── [другие файлы]
   ```

4. Нажмите **"Publish release"**

## Шаг 4: Получите прямую ссылку на игру

После публикации Release:

1. Нажмите правой кнопкой на файл `game.zip` в Release
2. Выберите **"Copy link address"**

Ссылка будет вида:
```
https://github.com/ВАШ_USERNAME/TwixLauncher/releases/download/game-v1.0/game.zip
```

**Сохраните эту ссылку!** Она нам понадобится.

# ЧАСТЬ 3: Настройка конфигурации

## Шаг 5: Создайте файл versions.json

1. В репозитории нажмите **"Add file" → "Create new file"**
2. Имя файла: `versions.json`
3. Содержимое:

```json
{
  "versions": [
    {
      "name": "Twix Game v1.0",
      "description": "Основная версия игры Twix",
      "download_url": "https://github.com/ВАШ_USERNAME/TwixLauncher/releases/download/game-v1.0/game.zip",
      "installed": false
    }
  ]
}
```

**Важно:** Замените `ВАШ_USERNAME` на ваш реальный username GitHub!

4. Нажмите **"Commit changes"**

---

# ЧАСТЬ 4: Автоматическая сборка лаунчера

## Шаг 6: Запустите GitHub Actions

GitHub Actions уже настроен через файл `.github/workflows/build-launcher.yml`

### Создайте Release для лаунчера:

1. Перейдите в **"Releases"**
2. Нажмите **"Create a new release"**

### Заполните форму:

```
Tag version: v1.0.0
   ↑ Это тег для ЛАУНЧЕРА (обязательно начинается с v)

Release title: Twix Launcher v1.0.0

Description:
   Первый релиз Twix Launcher!

   Возможности:
   - Автоматическая установка игры
   - Поддержка JAR и EXE файлов
   - Настройка выделенной RAM
   - Автоматическое обновление кнопки УСТАНОВИТЬ/ЗАПУСТИТЬ
```

3. **НЕ загружайте файлы** - GitHub Actions сделает это автоматически
4. Нажмите **"Publish release"**

## Шаг 7: Дождитесь сборки

1. Перейдите во вкладку **"Actions"**
2. Вы увидите запущенный workflow **"Build Twix Launcher"**
3. Дождитесь завершения (3-5 минут)
4. ✅ Зелёная галочка = успех!

## Шаг 8: Скачайте готовый лаунчер

1. Вернитесь в **"Releases"**
2. В релизе `v1.0.0` появится файл **`TwixLauncher-v1.0.0.zip`**
3. Скачайте его

### Что внутри архива:

```
TwixLauncher-v1.0.0.zip
├── TwixLauncher.exe       ← Готовый лаунчер!
├── ИНСТРУКЦИЯ.txt         ← Инструкция для пользователей
└── versions.json.example  ← Пример конфига
```

# 🛠️ Решение проблем

## GitHub Actions не запускается

**Проблема:** Workflow не появляется в Actions

**Решение:**
1. Проверьте что папка `.github/workflows/` существует
2. Проверьте что файл называется `build-launcher.yml`
3. Проверьте что файл закоммичен в main ветку
4. Зайдите в Settings → Actions → разрешите Actions

## Сборка падает с ошибкой

**Проблема:** Красный крестик в Actions

**Решение:**
1. Кликните на failed workflow
2. Посмотрите логи
3. Обычно проблема в `requirements.txt`
4. Убедитесь что все библиотеки корректны

## Лаунчер не скачивает игру

**Проблема:** Ошибка при скачивании

**Решение:**
1. Проверьте что ссылка в `versions.json` правильная
2. Проверьте что Release опубликован (не draft)
3. Попробуйте открыть ссылку в браузере
4. Убедитесь что репозиторий Public

## Java не найдена

**Проблема:** Лаунчер не может запустить JAR

**Решение:**
1. Установите Java: https://www.java.com/download
2. Перезапустите лаунчер
3. Лаунчер автоматически проверит Java
