# 🚀 Быстрый старт - Twix Launcher

## ✅ Что было сделано

### 1. Динамическая кнопка
- **Кнопка "УСТАНОВИТЬ"** (зелёная) - когда игра не установлена
- **Кнопка "ЗАПУСТИТЬ"** (голубая) - когда игра установлена
- Автоматически меняется после установки

### 2. Поддержка JAR файлов (Java игры)
- ✅ Автоматический поиск `.jar` файлов
- ✅ Запуск через Java с выделенной RAM
- ✅ Проверка наличия Java перед запуском
- ✅ Поддержка также `.exe` файлов

### 3. Автоматическая распаковка ZIP
- Скачивает игру
- Автоматически распаковывает ZIP-архив
- Удаляет архив после распаковки
- Обновляет кнопку на "ЗАПУСТИТЬ"

## 📦 Как подготовить вашу игру

### Шаг 1: Упакуйте игру в ZIP

Структура вашего ZIP архива:
```
game.zip
├── game.jar          ← Ваш JAR файл (главный)
├── assets/           ← Папки с ресурсами
├── data/
├── config/
└── [другие файлы]
```

**Важно:**
- JAR файл может быть в корне или в любой подпапке (лаунчер найдёт)
- Можете также добавить `.exe` лаунчер если есть

### Шаг 2: Разместите ZIP на хостинге

**Лучшие варианты (см. HOSTING_GUIDE.md):**

#### Вариант A: GitHub Releases (рекомендуется)
```
1. Создайте репозиторий на GitHub
2. Releases → Create new release
3. Загрузите game.zip
4. Получите ссылку:
   https://github.com/user/repo/releases/download/v1.0/game.zip
```

#### Вариант B: Mega.nz
```
1. Зарегистрируйтесь на mega.nz
2. Загрузите game.zip
3. Get link → используйте прямую ссылку
```

#### Вариант C: Свой сервер (лучшая производительность)
```
1. Разместите на VPS/сервере
2. Используйте прямую HTTP ссылку:
   http://yourdomain.com/downloads/game.zip
```

### Шаг 3: Создайте конфиг

Создайте файл `C:/Twix/versions.json`:

```json
{
  "versions": [
    {
      "name": "Twix Game v1.0",
      "description": "Основная версия игры",
      "download_url": "СЮДА_ВАШУ_ПРЯМУЮ_ССЫЛКУ",
      "installed": false
    }
  ]
}
```

**Пример с GitHub:**
```json
{
  "versions": [
    {
      "name": "Twix Game v1.0",
      "description": "Основная версия",
      "download_url": "https://github.com/yourusername/TwixGame/releases/download/v1.0/game.zip",
      "installed": false
    }
  ]
}
```

## 🎮 Как это работает

### Для пользователей:

1. **Запускают лаунчер** → Видят кнопку "УСТАНОВИТЬ" (зелёная)
2. **Нажимают "УСТАНОВИТЬ"** → Скачивается и устанавливается игра
3. **Кнопка меняется на "ЗАПУСТИТЬ"** (голубая)
4. **Нажимают "ЗАПУСТИТЬ"** → Игра запускается с выделенной RAM

### Что происходит при установке:

```
1. Скачивание ZIP архива (прогресс 0-70%)
   ↓
2. Распаковка в C:/Twix/Twix Game v1.0/ (70-90%)
   ↓
3. Удаление ZIP архива (90-100%)
   ↓
4. Кнопка меняется на "ЗАПУСТИТЬ"
```

### Что происходит при запуске JAR:

```
1. Проверка наличия Java
   ↓
2. Запуск: java -Xmx{RAM}M -jar game.jar
   ↓
3. Игра запущена в правильной директории
```

## 🛠️ Требования для пользователей

### Для JAR игр:
- ✅ **Java** должна быть установлена
- Скачать: https://www.java.com/download
- Лаунчер автоматически проверит и покажет подсказку если нет

### Для EXE игр:
- ✅ Никаких дополнительных требований
- Просто запускается напрямую

## 🧪 Как протестировать

### Локальное тестирование:

1. **Запустите простой HTTP сервер:**
   ```bash
   cd /папка/с/game.zip
   python -m http.server 8000
   ```

2. **Обновите versions.json:**
   ```json
   {
     "download_url": "http://localhost:8000/game.zip"
   }
   ```

3. **Запустите лаунчер:**
   ```bash
   python launcher.py
   ```

4. **Нажмите "УСТАНОВИТЬ"** и проверьте что:
   - Скачивается
   - Распаковывается
   - Кнопка меняется на "ЗАПУСТИТЬ"

5. **Нажмите "ЗАПУСТИТЬ"** и проверьте что игра запускается

## ⚙️ Настройки RAM

Пользователь может настроить RAM через слайдер (1-16 ГБ):
- **По умолчанию:** 2048 МБ (2 ГБ)
- **Рекомендуется:** 4096 МБ (4 ГБ)

При запуске JAR:
```bash
java -Xmx4096M -Xms2048M -jar game.jar
```
- `-Xmx` = максимальная RAM (из настроек)
- `-Xms` = минимальная RAM (половина от максимальной)

## ❓ Частые вопросы

### Q: Как пользователи узнают что нужна Java?
**A:** Лаунчер автоматически проверит и покажет сообщение со ссылкой на скачивание Java.

### Q: Можно ли несколько версий игры?
**A:** Да! Добавьте несколько объектов в `versions.json`:
```json
{
  "versions": [
    {"name": "v2.0", "download_url": "..."},
    {"name": "v1.5", "download_url": "..."},
    {"name": "v1.0", "download_url": "..."}
  ]
}
```

### Q: Что если JAR и EXE оба присутствуют?
**A:** Приоритет у JAR - он запустится первым. EXE запустится только если JAR нет.

### Q: Где хранится игра?
**A:** `C:/Twix/[Название версии]/`

### Q: Можно ли изменить путь установки?
**A:** Да, в launcher.py измените `GAME_PATH = "C:/Twix"`
