🎮 TWIX CLIENT LAUNCHER v1.0.0

Официальный лаунчер для TwixClient

📥 КАК УСТАНОВИТЬ:

1. Запустите TwixLauncher.exe
2. Нажмите зелёную кнопку "УСТАНОВИТЬ"
3. Дождитесь окончания загрузки
4. Нажмите голубую кнопку "ЗАПУСТИТЬ"
5. Играйте!

⚙️ СИСТЕМНЫЕ ТРЕБОВАНИЯ:

- Windows 7/8/10/11
- Java 8 или выше (скачать: https://www.java.com/download)
- RAM: минимум 2 ГБ, рекомендуется 4 ГБ
- Интернет для скачивания

🎛️ НАСТРОЙКИ:

RAM (оперативная память):
- Двигайте слайдер для настройки (1-16 ГБ)
- Рекомендуется: 4096 МБ (4 ГБ)
- Больше RAM = плавнее игра

📁 ИГРА УСТАНАВЛИВАЕТСЯ:

C:\Twix\TwixClient v1.0.0\

❓ ПРОБЛЕМЫ?

"Java не найдена"
→ Установите Java: https://www.java.com/download

"Не удалось скачать"
→ Проверьте интернет
→ Отключите антивирус временно

"Игра не запускается"
→ Переустановите (удалите папку C:\Twix и установите заново)
