# Twix Launcher - Инструкция на русском

## 🎮 Быстрый старт

### Для пользователей (готовый .exe файл)

1. **Скачайте** `TwixLauncher.exe`
2. **Запустите** двойным кликом
3. **Нажмите** кнопку "СКАЧАТЬ ИГРУ"
4. **Дождитесь** завершения загрузки и установки
5. **Нажмите** кнопку "ЗАПУСТИТЬ"

Всё! Игра установится автоматически в `C:/Twix/`

## ⚙️ Настройка своей игры

### Шаг 1: Загрузите игру на хостинг

Поддерживаемые хостинги:
- **Google Drive** ✅ (рекомендуется)
- **Dropbox** ✅
- **Mega.nz** ✅
- **Свой сервер** ✅

### Шаг 2: Получите прямую ссылку

#### Для Google Drive:

1. Загрузите zip-архив с игрой
2. Нажмите ПКМ → "Получить ссылку"
3. Установите "Доступ по ссылке" → "Всем"
4. Скопируйте ссылку (любой формат)

**Лаунчер автоматически конвертирует любую ссылку Google Drive!**

Поддерживаемые форматы:
- `https://drive.google.com/file/d/ID/view`
- `https://drive.google.com/open?id=ID`
- `https://drive.google.com/uc?export=download&id=ID`

#### Для Dropbox:

1. Загрузите файл
2. Получите ссылку для общего доступа
3. Замените `www.dropbox.com` на `dl.dropboxusercontent.com`
4. Уберите `?dl=0` в конце

### Шаг 3: Отредактируйте конфиг

Откройте файл `versions.json` и отредактируйте:

```json
{
  "versions": [
    {
      "name": "Моя Игра v1.0",
      "description": "Описание версии игры",
      "download_url": "ВАША_ССЫЛКА_СЮДА",
      "installed": false
    }
  ]
}
```

**Важно:**
- Игра должна быть запакована в **ZIP-архив**
- Внутри архива должен быть **.exe файл** игры
- Структура не важна - лаунчер найдёт .exe автоматически

## 🎨 Настройка интерфейса

### Изменить цвета

Отредактируйте `launcher.py`:

```python
# Фон
fg_color="#1a1a2e"    # Тёмно-синий

# Панели
fg_color="#16213e"    # Синий

# Акцентный цвет (кнопки)
text_color="#00d4ff"  # Голубой
```

### Добавить свою иконку

1. Создайте `.ico` файл (256x256 пикселей)
2. Сохраните как `icon.ico` в папке проекта
3. Отредактируйте `build_exe.py` - раскомментируйте строку:
   ```python
   "--icon=icon.ico",
   ```
4. Пересоберите: `python build_exe.py`

### Изменить путь установки

По умолчанию игра устанавливается в `C:/Twix`

Чтобы изменить, отредактируйте в `launcher.py`:
```python
GAME_PATH = "C:/Twix"  # Измените на свой путь
```

## ❓ Частые проблемы

### "Python не найден"
**Решение:** Установите Python с python.org, отметьте "Add Python to PATH"

### "No module named 'customtkinter'"
**Решение:**
```bash
pip install -r requirements.txt
```

### Игра не скачивается
**Проверьте:**
- Интернет соединение
- Правильность ссылки (откройте в браузере)
- Доступ к файлу (должен быть открытый доступ)
- Антивирус (может блокировать)

### Игра не запускается
**Проверьте:**
- Наличие .exe файла в `C:/Twix/[название версии]/`
- Права доступа к файлу
- Попробуйте запустить .exe напрямую
- Установлены ли необходимые библиотеки (Visual C++, DirectX и т.д.)

### Google Drive говорит "слишком много скачиваний"
**Решение:**
- Используйте другой аккаунт Google Drive
- Разместите на другом хостинге (Mega.nz, Dropbox)
- Используйте свой сервер
